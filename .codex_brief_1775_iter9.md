# Codex audit — iteration 9 — issue #1775, PR #1776 (head cf4b14051)

## What this branch does

Grounds the causal-analysis clinical-context panel in the SCENARIO being analysed.
Before, the panel showed accurate indication/mechanism/RWE facts that were identical
regardless of which outcome the causal analysis estimated, and for COMMERCIAL levers
it shipped an honest refusal. Now it also returns `analysis_grounding`: verbatim FDA
label considerations selected by relevance to the analysed outcome, plus competitive
framing, plus a note tying them to the commercial question. Zero new upstream calls —
the openFDA label is already fetched for the indications fragment.

## What changed since iteration 8

All four findings accepted and fixed.

1. HIGH, grounding layer — the one that mattered. `_competitive_context` fell through
   to a generic "Same-class alternatives in X" for an outcome `_theme_for` explicitly
   declined to map, rendered under "What bears on this analysis". Borrowed relevance,
   the exact complaint #1763 was filed about. No theme now yields no claims at all.
2. HIGH, the documented bound was wrong about TITLES: a bullet without its own heading
   gets this module's section name, our words not the label's. Only the DETAIL is
   guaranteed verbatim. Corrected, `boxed_warning_consideration` included.
3. HIGH, range references. `_CANDIDATE` matched comma lists but not "( 5.1-5.3 )", so
   a range terminal was invisible both as a boundary and to the invariant — the last
   combination producing a MERGE. 0 occurrences across 20 labels / 60 sections; fixed
   anyway because the fix is ADDITIVE (it can only make a reference visible).
4. MEDIUM, the panel note. Found and fixed independently before your report landed;
   your read of the tree predates the commit. The note now renders on its own.

Re-measured after the parser change: 20 labels / 60 sections / 176 items, 0 differing
from the last verified parity point, 0 verbatim violations.
